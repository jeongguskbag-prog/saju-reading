# 기획: 결제 후 미리보기 + 상품별 지연 발송 (기획 단계, 아직 구현 안 함)

작성: 2026-10-20 · 상태: 기획 중 (사장님이 "빌드해 줘" 하기 전까지 구현하지 않는다)

## 배경
다른 온라인 사주 서비스처럼, 유료 감정서는 결제 즉시 보여 주지 않고 몇 시간 뒤 메일·문자(·알림톡)로 보낸다.
현재는 결제 3분 뒤 화면 공개(WEB_REVEAL_MINUTES) + 같은 시각 발송 예약(QStash)이다. 이 장치의 시간을 상품별로 늘리고 경험을 다듬는다.

## 결제 직후: 미리보기(계산값만, 해석 글은 없음)
| 상품 | 바로 보여 줄 것 |
|---|---|
| 핵심 명식록 · 종합 감정서 | 여덟 글자 명식표, 오행 분포, 사주 유형, 대운 흐름표, 한 줄 요약 |
| 연분록(궁합) | 두 사람 명식표, 오행 비교, 궁합 큰 등급 |
| 신년 운세록 | 명식표, 올해 세운 간지, 월별 흐름(좋음·보통·주의 표시만) |
| 택일록 | 요청 요약(목적·기간), 후보 날짜 개수 |
| 주역 점 | 괘 그림·괘 이름·변효 |
| 자미두수 명반 | 12궁 명반 그림 |
| 작명록 | 명식표, 부족한 오행 분석 |

안내 문구 예: "감정서 본문은 명식을 바탕으로 작성 중이며, 오늘 오후 3시 10분 전후에 이메일·문자로 보내 드립니다."

## 상품별 발송 시간(제안, 관리 설정에서 상품별로 바꿀 수 있게)
| 상품 | 가격 | 발송 |
|---|---|---|
| 주역 점 | 9,900 | 30분 뒤 |
| 신년 운세록 | 19,000 | 1시간 뒤 |
| 핵심 명식록 · 택일록 | 29,000 | 1시간 뒤 |
| 연분록 · 자미두수 | 39,000 | 2시간 뒤 |
| 종합 감정서 | 49,000 | 2시간 뒤 |
| 작명록 | 70,000 | 3시간 뒤 |

## 규칙
- 밤 22:00~08:00에 걸리면 08:00 발송(예정 시각 안내에도 반영).
- 기다리는 동안 감정서 링크·주문 조회로 들어오면: 미리보기 + "○시 전후 발송" 안내.
- 감정서 본문은 결제 직후 미리 생성해 두고 공개·발송 시각만 늦춘다.
- 무료 사주 유형 보기, AI 상담은 지금처럼 즉시.
- 관리자: 예약 목록, 지금 보내기, 발송 전 미리 보기, 결제 취소(토스 취소 연동).
- 문구 수정: 첫 화면·감정서 안내·FAQ·결제 버튼 근처의 "결제 후 약 3분" 표현, 환불 규정·약관.

## 미정(사장님 결정 필요)
- 발송 시간 표 확정.
- 발송 전 취소: 전액 환불 / 미리보기 제공분 공제 등.
- (나중에) 유료 '바로 받기' 옵션 여부.

## 관련: 가상계좌 결제(2026-10-20 문의)
- 토스페이먼츠 결제창 method "VIRTUAL_ACCOUNT"로 가능. 토스 상점관리자에서 가상계좌 결제수단 계약·사업자 필요.
- 입금 대기 상태 → 입금되면 토스 웹훅으로 결제 완료 처리 → 그때부터 위 지연 발송 시작.
- 필요: 입금 대기 화면(계좌번호·은행·입금 기한·금액), 계좌 안내 문자·메일, 웹훅(입금 확인/기한 만료), 입금 기한 지난 주문 정리,
  환불 시 고객 환불 계좌 받기, 현금영수증 신청 칸.

## 관련: 휴대폰 소액결제(2026-10-20 문의)
- 이미 구현되어 있음(결제 화면 '카드/휴대폰' 버튼). 토스 상점관리자에서 휴대폰 결제 계약(사업자 필요, 통신사 심사) 후
  Vercel `TOSS_MOBILE_PHONE=1` + Redeploy로 켠다.
- 수수료가 카드보다 높고(보통 5% 전후), 정산이 늦고, 사주·운세 업종 심사가 까다로울 수 있음. 월 한도에 고가 상품이 걸릴 수 있음.
- 사업자등록증이 나오면 가상계좌와 함께 토스에 신청.

## 아이디어: 충전식 '천기 포인트'(2026-10-20, 포스텔러 '포스 충전소' 참고)
### 무엇
- 돈을 먼저 포인트로 충전하고 감정서·AI 상담·주역 점 등을 포인트로 결제. 한 번 충전하면 다음 구매는 결제창 없이 바로.
- 충전 보너스(예: 첫 충전 1+1, 많이 충전할수록 보너스 비율↑)로 객단가를 올린다.
- 참고: 포스텔러 화면 — 500포스 5,500원, 900포스 9,900원, '첫 충전 1+1', 상품 결제 시 부족분 안내("1,000포스가 더 필요합니다").

### 지금 있는 것과의 관계
- AI 상담 질문권(5회 4,900원 / 15회 9,900원)이 이미 작은 형태의 충전식 상품이다. 회원(카카오 로그인)에 묶여 있다.
- 1단계(안전): 질문권 묶음을 키운다(보너스 질문, 첫 구매 혜택). 질문권은 AI 상담에만 쓰므로 규제 부담이 적다.
- 2단계(검토 후): 여러 상품에 쓰는 '천기 포인트'로 확장.

### 화면 흐름(2단계 기준)
1. 마이 > 내 포인트(잔액, 충전 내역, 사용 내역).
2. 충전소: 충전 금액 묶음과 보너스 표시, 토스로 결제.
3. 상품 결제 화면: '포인트로 결제' 선택지. 부족하면 부족분과 바로 충전 버튼.
4. 결제 후 흐름은 카드 결제와 동일(미리보기 → 상품별 지연 발송).

### 조심할 점
- 여러 상품에 쓰는 선불 충전금은 전자금융거래법상 '선불전자지급수단'에 해당할 수 있음. 소규모 면제 기준 등은 전문가 확인 필요(변호사·세무사).
- 쓰지 않은 유상 충전금은 요청 시 환불해야 함. 보너스(무상) 포인트는 환불 제외·유효기간을 약관에 명시.
- 유효기간(예: 유상 5년, 보너스 1년) 정하기.
- 회원 전용(카카오 로그인). 탈퇴 시 잔액 처리 안내.
- 매출 인식: 충전 시점이 아니라 사용 시점이 매출(세무 확인 필요).
- 관리 화면: 회원별 잔액, 충전·사용·환불 내역, 수동 지급(보상) 기능.

### 미정
- 1단계로 시작할지, 바로 2단계로 갈지.
- 충전 금액표와 보너스 비율, 유효기간.

## 추가 아이디어 모음(2026-10-20, Claude 제안)
추천 순서: 3(신년 시즌) → 1(감정서→AI 상담) → 4(공유 카드) → 2(선물하기). 신년 시즌이 두 달 앞이라 3번이 가장 급하다.

### 1. 감정서 → AI 상담 이어 주기 (작음 · 효과 큼)
- 감정서 마지막 장, 발송 메일·문자에 "이 감정서로 궁금한 점 바로 물어보기" 버튼.
- 감정서 구매자에게 AI 상담 무료 질문 1~2회 지급(회원이면 자동, 비회원이면 가입 시 지급).
- 같은 계산 엔진이라 감정서 내용과 상담 답이 어긋나지 않는다는 점을 안내.

### 2. 선물하기 (중간 · 시즌 효과 큼)
- 사는 사람이 결제 → 받는 사람에게 선물 링크(문자·카톡·메일) → 받는 사람이 생년월일시 입력 → 감정서 생성·발송.
- 선물 메시지 카드, 선물 링크 유효기간, 미사용 시 환불 규칙.
- 설날(2027년 2월)·어버이날·생일 시즌. 신년 운세록·종합 감정서가 선물용으로 적합.

### 3. 2027 정미년(丁未年) 신년 시즌 (작음 · 매우 중요)
- 12월 초부터 첫 화면 "2027 정미년 신년 운세" 배너.
- 가족 묶음(3~4인 신년 운세 할인).
- 회원에게 "올해 운세 정리 + 내년 미리보기" 안내.
- 신년 운세록이 2027년 기준으로 나오는지 점검(세운·월별 흐름 연도 전환 시점).

### 4. 무료 사주 유형 '공유 카드' (작음 · 홍보 효과)
- 무료 유형 결과를 인스타 스토리(9:16)·카톡용 이미지 카드로 저장·공유.
- 카드 아래 천기록 주소, 이름은 넣지 않거나 선택.

### 5. 함께 사면 할인·다음 상품 제안 (작음)
- 결제 완료 화면·발송 메일에 다음 상품 한 줄 제안(예: 종합 감정서 → 연분록 20% 할인).
- 할인 코드 또는 기간 한정 가격. 결제 금액 검증은 서버에서.

### 6. 후기·친구 초대 보상 (작음~중간)
- 후기 작성 시 AI 질문권 1회(후기 기능은 이미 있음). 1주문당 1회.
- 친구 초대 링크로 친구 첫 구매 시 둘 다 질문권. 자기 초대·중복 계정 방지.

### 7. 매달 '이달의 운세' 알림 (중간 · 재방문)
- 회원에게 매달 1일 이번 달 흐름 요약 → 자세한 건 AI 상담으로.
- 광고성 메시지라 수신 동의 필수, 21:00~08:00 발송 금지, 수신 거부 방법 안내, '(광고)' 표기 등 규칙 준수.

### 8. 무료 콘텐츠 페이지로 검색 유입 (중간 · 장기)
- '오늘의 일진', '띠별 이번 주 운세', '만세력 조회' 등 무료 페이지.
- 검색 노출용 제목·설명, 네이버 서치어드바이저·구글 서치콘솔 등록.

  사주 유형 공유 카드, 후기 보상(질문 1회)·함께 보면 좋은 감정서, 선물하기(/gift).
