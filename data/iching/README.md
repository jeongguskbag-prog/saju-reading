# 주역(周易) 본문

`zhouyi.json`: 64괘의 괘사·대상·효사(용구·용육 포함). 본문은 공유 저작물(고전)이며, 데이터는 [@freizl/yijing](https://www.npmjs.com/package/@freizl/yijing) 2.1.0(MIT, zh-TW)에서 가져와 다음을 바로잡았다.

- 간체→번체 변환 오류: 兇→凶, 鹹→咸, 裏→里, 誌→志, 鬥→斗, 系於金柅→繫于金柅, 後以(군주)→后以, 後不省方→后不省方
- 대상 오자: 虩雷→洊雷(震), 雲，雷→雲雷(屯)
- 대유(大有) 구이 효사가 동인(同人) 육이로 잘못 들어간 것: 大車以載，有攸往，無咎。
- 구(姤) 구오가 두 번 들어간 것

`bits`는 아래(초효)에서 위(상효) 순서, 1이 양효. `ko`는 한국어 괘 이름 읽기.
