# 감정서 견본

`public/samples/`의 견본 PDF와 미리 보기 그림은 가상의 의뢰인으로 실제 감정서와 같은 화면·인쇄 과정을 거쳐 만든 것입니다.

- 종합 감정서·핵심 명식록: 홍길동, 1990년 5월 15일 10시 30분(양력) 남성
- 길운 개운 작명록: 김○○, 2026년 9월 3일 7시 10분(양력) 여아, 성씨 김(金), 느낌 지혜·온화

풀이 문장은 `saju-texts.json`, `naming-texts.json`에 있습니다(명식 값에 맞춰 천기록이 직접 쓴 견본 문장).
다시 만들 때는 AI 대신 이 문장을 돌려주는 시험용 서버를 `ANTHROPIC_BASE_URL`로 연결해 주문·결제(시험용)·인쇄를 거친 뒤,
A4로 PDF 저장하고 몇 쪽을 300px 너비 JPG로 줄입니다. 쪽수가 바뀌면 `src/components/SamplePreview.tsx`의 pages도 고칩니다.
